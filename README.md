## About

<img align="right" width="260" src="https://skillicons.dev/icons?i=kali&theme=dark" />

I'm a **BS Cybersecurity** student at Air University Islamabad (Honhaar Merit Scholar) and the founder of **Tauqeer Mustafa Inc. (TMI)** — a cybersecurity and technology consultancy based in Islamabad, Pakistan, built to give small and mid-sized businesses access to security practices usually reserved for larger enterprises.

At TMI I work across:

- **Cybersecurity assessments** — vulnerability scanning, risk reviews, hardening recommendations
- **Incident response** — investigation, containment, and remediation support
- **Compliance advisory** — aligning SME processes with recognized security frameworks
- **Web development** — building and securing client-facing web infrastructure

My personal focus sits between **offensive security** and **applied AI in security tooling** — I build small, dependency-light utilities that solve real problems in git workflows, infrastructure, and security auditing rather than shipping bloated frameworks.

I hold cybersecurity certifications from **Google** and **Microsoft** (via Coursera), and I've co-authored two peer-reviewed publications, in *Clinical Infectious Diseases* (2023) and *Expert Review of Anti-infective Therapy* (2023).
